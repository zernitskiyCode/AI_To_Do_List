# Frontend - Календарь (Вариант 2: Balanced)

## 1. Форма создания задачи (AddTaskForm.jsx)

### Добавить поле выбора даты и времени
- Добавить в `initialState`: `dueDate: null`, `dueTime: null`
- Создать компонент `DateTimePicker` или использовать нативный `<input type="datetime-local">`
- Добавить в форму после поля "Категория"
- Сделать опциональным (можно создать задачу без дедлайна)
- В `handleSubmit` отправлять `deadline` вместо `dueDate: null`
- Формат: ISO 8601 (`2024-03-27T14:30:00`)

### UI элементы
- Label: "Срок выполнения" (опционально)
- Кнопки быстрого выбора: "Сегодня", "Завтра", "Через неделю"
- Кнопка "Очистить дату" если дата выбрана


## 2. Страница Calendar (Calendar.jsx)

### Создать компонент CalendarView
- Месячная сетка (7 дней × 4-6 недель)
- Навигация: предыдущий/следующий месяц
- Показать текущий месяц и год
- Выделить сегодняшний день

### Отображение задач на датах
- Точки/бейджи с количеством задач на каждой дате
- Цветовая кодировка по приоритету (high=красный, medium=оранжевый, low=синий)
- Клик на дату → показать список задач на этот день (модалка или боковая панель)

### Компоненты
- `CalendarGrid` - сетка календаря
- `CalendarDay` - отдельный день с задачами
- `DayTasksModal` - модалка со списком задач на выбранный день


## 3. Хуки

- Состояние: `currentMonth`, `currentYear`, `selectedDate`
- Методы: `nextMonth()`, `prevMonth()`, `selectDate(date)`

- Добавить функцию `getTasksByDate(date)` → `/tasks/by-date?date=YYYY-MM-DD`

## 4. Обновления существующих компонентов

### TaskList.jsx
- Уже показывает `dueDate` - должно заработать автоматически
- Проверить форматирование даты

### AddTaskForm.jsx
- Изменить `dueDate: null` → `deadline: <выбранная дата>`
- Валидация: дата не может быть в прошлом (опционально)


## 5. Утилиты (опционально)

### utils/dateHelpers.js
- `formatDate(date)` - форматирование для отображения
- `isSameDay(date1, date2)` - сравнение дат
- `getMonthDays(year, month)` - получить все дни месяца
- `groupTasksByDate(tasks)` - группировка задач по датам
