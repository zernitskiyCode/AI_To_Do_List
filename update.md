## Как это работает

### Создание задачи с категорией:

1. **Выбор существующей категории**:
   - Пользователь видит все доступные категории (дефолтные + свои)
   - Выбирает нужную категорию
   - Создает задачу

2. **Создание новой категории**:
   - Пользователь нажимает "+ Создать свою категорию"
   - Вводит название новой категории (макс. 50 символов)
   - Создает задачу
   - Новая категория автоматически появится в списке при следующей загрузке

### Фильтрация по категориям:

- В фильтрах отображаются все категории пользователя
- Можно фильтровать задачи по любой категории (включая пользовательские)
- Категория "Все" показывает все задачи

### Отображение категорий:

- Дефолтные категории: `Работа`, `Личное`, `Здоровье`, `Учеба`
- Пользовательские категории: отображаются с заглавной буквы (например: `Спорт`, `Хобби`)

## Технические детали

### Backend:
- **Endpoint**: `GET /categories`

### База данных:

- **Обратная совместимость**: Все существующие задачи работают без изменений

## 🎨 УЛУЧШЕНИЕ UI: Ограничение количества категорий в фильтрах (12.02.2026)

### Проблема
При большом количестве категорий UI фильтров выглядит перегруженным

### Решение
Показываем только топ-6 самых используемых категорий в фильтрах

### Изменения

#### Backend

##### 1. Разделены функции получения категорий
- **Файл**: `backend/database/crud.py`

**Новая функция**: `get_all_user_categories(user_id)`
- Возвращает ВСЕ категории пользователя
- Используется для формы создания задачи

**Обновленная функция**: `get_user_categories(user_id)`
- Возвращает топ-6 самых используемых категорий
- Используется для фильтров
- SQL запрос с `COUNT(*)` и `ORDER BY count DESC LIMIT 6`

##### 2. Новый endpoint
- **Файл**: `backend/main.py`
- **Endpoint**: `GET /categories/all`
- **Описание**: Возвращает все категории для формы создания задачи

**Обновленный endpoint**: `GET /categories`
- Теперь возвращает только топ-6 категорий

#### Frontend

##### 1. Новая функция API
- **Файл**: `src/hooks/getTasks.js`
- **Функция**: `getAllCategories()`
- **Описание**: Запрос к `/categories/all`

##### 2. Новый хук
- **Файл**: `src/hooks/useCategories.js`
- **Хук**: `useAllCategories()`
- **Описание**: Получает все категории для формы создания задачи

##### 3. Обновлена форма создания задачи

- **Изменение**: Использует `useAllCategories()` вместо `useCategories()`
- **Результат**: Показывает все категории в форме

##### 4. Фильтры остались без изменений
- **Файл**: `src/components/TaskFilters/TaskFilters.jsx`
- **Использует**: `useCategories()` - показывает только топ-6

##### 5. Обновлена инвалидация кеша

### Логика работы

1. Пользователь создает задачи с разными категориями
2. Backend считает количество задач для каждой категории
3. В фильтрах показываются:
   - 4 дефолтные категории (всегда)
   - Топ-6 самых используемых пользовательских категорий
4. В форме создания задачи доступны все категории
