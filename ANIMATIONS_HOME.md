# Анимации на странице Home

## Что было добавлено:

### 1. Базовые анимации (_variables.scss)
- `slideUpFade` - появление снизу вверх (для основных компонентов)
- `slideDownFade` - появление сверху вниз (для задач и фильтров)
- `fadeIn` - простое появление
- Миксины для удобного применения анимаций

### 2. Анимации при загрузке страницы (Home.scss)
Последовательное появление компонентов снизу вверх:
- VoiceInputCard - 0.1s задержка
- SearchBar - 0.2s задержка
- TaskFilters (sticky header) - 0.3s задержка
- AddTaskButton - 0.4s задержка
- TaskList - 0.5s задержка

### 3. Анимации фильтров (TaskFilters.scss)
- Фильтры приоритета появляются последовательно (по 0.05s задержка)
- Категории появляются после приоритетов (начиная с 0.3s)
- Эффект "волны" при загрузке
- **Одинаковые hover эффекты** для приоритетов и категорий (translateY(-2px))

### 4. Анимации задач при скролле (TaskList.jsx + TaskList.scss)
- Использован Intersection Observer API
- **Задачи анимируются каждый раз при скролле** (не только при первой загрузке)
- При выходе из viewport класс удаляется, при возврате - добавляется снова
- Плавное появление сверху вниз
- Threshold: 10% видимости элемента
- Используется transition вместо animation для повторяемости

### 5. Улучшенные hover эффекты
- **VoiceInputCard**: мягкий scale (1.03) + небольшой подъем (1px)
- SearchBar: подсветка при фокусе
- AddTaskButton: вращение иконки "+" на 90° при наведении
- **Приоритеты и категории**: одинаковый эффект подъема (translateY(-2px))
- Все эффекты используют cubic-bezier для плавности

## Технические детали:

- Все анимации легкие и быстрые (0.4-0.5s)
- Используется `cubic-bezier(0.4, 0, 0.2, 1)` для естественного движения
- Анимации не блокируют взаимодействие с элементами
- Адаптивность сохранена для мобильных устройств
- PageHeader и BottomNav не анимированы (как требовалось)

## Как это работает:

1. При загрузке страницы компоненты появляются последовательно
2. Фильтры "выстреливают" один за другим
3. **При скролле задачи появляются/исчезают динамически**
4. Hover эффекты единообразны и не резкие
